Claude Code Statusline 產生器

設計 Claude Code 的自訂狀態列：勾選要顯示的 segment、拖曳或用上下鈕排序、選顏色與百分比閾值變色，即時預覽，一鍵產出 bash（.sh）與 PowerShell（.ps1）腳本，以及 settings.json 片段。所有處理都在瀏覽器端完成，不會上傳任何資料。
